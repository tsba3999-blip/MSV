GO English — голосовой ответ удержанием GO

Сценарий: в текущем уроке удержать GO, произнести английскую фразу, отпустить.
До20секунд; мышь, касание и удержание Space/Enter. Первый раз браузер спрашивает
разрешение. Если отпустить до разрешения, запись не отправляется: нажать снова.
Пауза, выход, скрытие вкладки и отмена останавливают микрофон и запрос.
Показываются распознанные слова и пример. Только точные известные примеры
получают заданное объяснение; другие формулировки не объявляются ошибкой.
Это не свободный разговор и не оценка произношения. Прогресс/рейтинг остаются демо.

УСТРОЙСТВО
web/english/src/capture.js — MediaRecorder и состояния; src/app.js — урок.
POST /api/english/transcribe: действующий активный аккаунт, совпадающая роль,
обычная защита от отозванных сеансов, запрет просмотра чужого кабинета,
Origin=https://go.1msv.ru, JSON, до1МиБ аудио,30попыток за5минут на аккаунт.
Один запрос распознавания одновременно; занятость даёт понятный повтор.
Маршрут server/routes/english-speech.js отправляет байты только localhost3034.
Сервер транскрипции transcribe.py: CPU int8, один поток, base.en, английский язык.
Тишина/повреждение/длинная запись возвращают422. Тайм-аут приложения25секунд.
Приложение не пишет аудио/текст в базу, файлы или журнал. Ответы no-store.
PyAV декодирует из памяти. Отключение сетевого запроса не обещает мгновенную
остановку уже начавшегося вычисления, но его результат больше не показывается.

РАЗВЁРТЫВАНИЕ
Нынешний сервер Timeweb, Ubuntu22.04, Python3.10; основной сайт msv-1go на3032.
Изолированная среда /opt/msv-english-speech/venv; модель в соседнем model/.
Новые платные сервисы, внешние API и ключи не используются.

1. Создать /opt/msv-english-speech и python3 -m venv в venv/.
   Если системный ensurepip отсутствует, использовать --without-pip и проверенный
   wheel pip25.3 с официального PyPI через PYTHONPATH; системный Python не менять.
   Установить requirements-lock.txt только в эту среду с --only-binary=:all:.
2. Скачать четыре файла из https://huggingface.co/Systran/faster-whisper-base.en
   по revision из model-manifest.json в model/, сверить каждый размер и SHA256.
   Модель и зависимости не включать в web или Git. Сохранить лицензии пакетов.
3. Скопировать transcribe.py в /opt/msv-english-speech/; unit из этой папки
   в /etc/systemd/system/. systemctl daemon-reload; start msv-english-speech.
   Проверить http://127.0.0.1:3034/health и учебную запись. Порт не публиковать.
   Unit запускает отдельного пользователя, ограничивает RAM/CPU, запрещает
   исходящую сеть, запись в системные каталоги и core dump.
4. В HTTPS server{} go.1msv.ru добавить nginx-location.conf до location /.
   Он охватывает и завершающий слеш, отключает временные файлы аудиотела/ответа,
   задаёт достаточный буфер памяти. Проверить nginx -t и перечитать конфигурацию.
   Без этого шага обещать отсутствие временного хранения аудио нельзя.
5. Подключить маршрут в server/index.js и разрешить microphone=(self) только
   для HTML English; камера/геолокация и остальные страницы остаются закрыты.
   В GitHub узкая разница server/index.js сохранена в docs/english/input-integration.patch.
   Сверить базовый файл: старый main нельзя накатывать поверх восстановленного сайта.
6. Опубликовать серверный маршрут, затем src/capture.js, src/app.js, styles.css,
   build.py и собранный index.html. Сохранить копии и проверить хэши перед заменой.
   Перезапустить msv-1go, проверить health/гостевой отказ/вход/запись/прежнюю озвучку.
   После проверок systemctl enable msv-english-speech — работает без компьютера.

ПРОВЕРКА И ОТКАТ
Проверять синтетические учебные записи; не сохранять записи жильцов для тестов.
Проверить WAV, WebM/Opus, OGG/Opus, MP4/AAC, тишину, размер, длительность,
неактивный/отозванный аккаунт, чужой Origin,30попыток, занятость и повтор.
В браузере — удержание/отпускание, разрешение/отказ,20секунд, выход/пауза,
повтор, отсутствие оставшегося микрофона и небезопасной HTML-вставки текста.
Chrome мобильная эмуляция не заменяет проверку Safari/Android на устройстве.
Для отката восстановить только файлы выпуска и nginx из копии, nginx -t/reload,
перезапустить основной сайт. Базы/кабинеты/таймеры резервирования не меняются.
Отключать службу распознавания только если откат действительно нужен.
