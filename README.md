# Шахматка заселения для МСВ

Модуль показывает сетку «места × дни», подсказку при наведении на фамилию
и выезжающую справа карточку проживающего.

Работает сам по себе: никаких библиотек ставить не нужно.

## Что в папке

| Файл | Зачем |
|---|---|
| `shahmatka.css` | оформление |
| `shahmatka.js` | вся логика |
| `demo.html` | страница с вымышленными данными, чтобы посмотреть, как выглядит |
| `install-shahmatka.sh` | ставит модуль на сервер и подключает его |
| `README.md` | этот файл |

---

## Часть 1. Как положить файлы на GitHub

Без командной строки, прямо через сайт.

1. Откройте свой репозиторий: `https://github.com/tsba3999-blip/MSV`
2. Нажмите **Add file** → **Upload files**.
3. Перетащите в окно браузера **всю папку `shahmatka`** целиком.
   GitHub сохранит её как папку `shahmatka` внутри проекта.
4. Внизу страницы в поле описания напишите, например,
   `Добавлена шахматка заселения`.
5. Нажмите зелёную кнопку **Commit changes**.

Готово. В репозитории появится папка `shahmatka` рядом с `assets`
и `deploy-msv.sh`.

## Часть 2. Как перенести файлы на сервер

Подключитесь к серверу и выполните команды по очереди:

```bash
cd /var/www/MSV
git pull
bash shahmatka/install-shahmatka.sh
```

Скрипт скопирует файлы, подключит их к сайту и перезапустит приложение.
Запускать его повторно безопасно — ничего не задвоится.

Проверьте демо в браузере:

```
http://104.171.138.117/shahmatka/demo.html
```

Если страница открылась и по полосам можно кликать — модуль на месте.

### Если что-то пошло не так

Скрипт перед правкой делает копию `index.html`. Вернуть как было:

```bash
ls /opt/msv/index.html.bak-*
cp /opt/msv/index.html.bak-ВАША_ДАТА /opt/msv/index.html
systemctl restart msv
```

---

## ⚠ Важное предупреждение

Файлы `/opt/msv/app.js` и `/opt/msv/index.html` **создаются заново каждый раз,
когда вы запускаете `deploy-msv.sh`**. Это значит:

- сама папка `/opt/msv/shahmatka/` при повторном развёртывании уцелеет;
- а вот две строчки подключения в `index.html` пропадут.

Поэтому после каждого запуска `deploy-msv.sh` заново выполняйте:

```bash
bash /var/www/MSV/shahmatka/install-shahmatka.sh
```

Правильное решение на будущее — перенести подключение внутрь самого
`deploy-msv.sh`, чтобы оно ставилось автоматически. Пока достаточно помнить
про эту команду.

## Часть 3. Как показать шахматку на странице сайта

В том месте интерфейса, где должна появиться шахматка, нужен пустой блок:

```html
<div id="shahmatka" style="height:640px"></div>
```

И вызов:

```js
var sh = MSVShahmatka.mount('#shahmatka', данные, {
  title: 'Шахматка заселения',
  days: 35,
  onEdit: function (booking) { /* открыть форму брони */ },
  onOpenProfile: function (resident) { /* открыть профиль */ }
});
```

Высоту задавать обязательно — без неё блок схлопнется в ноль и вы
ничего не увидите.

### Откуда брать данные

Если структура `db` в вашем `app.js` совпадает по названиям полей,
подойдёт готовый переходник:

```js
var sh = MSVShahmatka.mount('#shahmatka', MSVShahmatka.fromMSV(db));
```

Если названия полей другие — правьте функцию `fromMSV` в конце
`shahmatka.js`, а не остальной код.

### Формат данных

```js
{
  buildings: [{ id, name }],
  rooms:     [{ id, buildingId, number, name, gender }],   // gender: 'ж' | 'м'
  beds:      [{ id, roomId, label, tier }],                // label: '5.2.в'
  residents: [{ id, name, phone, birthday, docsSigned, city,
                university, program, contactPerson, vk, photo }],
  bookings:  [{ id, bedId, residentId, from, to, checkIn, checkOut,
                source, tariff, accrued, paid, bookedAt, note, status }],
  payments:  [{ id, residentId, period, amount, date, kind }]
}
```

Даты — строкой `'2026-09-01'` или `'01.09.2026'`.
`accrued` — начислено, `paid` — оплачено; разница показывается как долг.

Поле `status` можно не задавать — модуль вычислит сам:

| Статус | Когда |
|---|---|
| Забронировано | заезд ещё впереди |
| Проживает | сейчас живёт |
| Скоро выезд | выезд в течение недели |
| Есть долг | оплачено меньше, чем начислено |
| Выехал | срок закончился, долгов нет |

### Методы

```js
sh.setData(данные);          // заменить данные
sh.setStart('2026-09-01');   // перейти к дате
sh.openBooking('bk1');       // открыть карточку
sh.closePanel();             // закрыть карточку
sh.refresh();                // перерисовать
sh.destroy();                // убрать со страницы
```

### Цвета

Все цвета — переменные CSS. Чтобы перекрасить под фирменный стиль,
не трогая `shahmatka.css`, добавьте в свой файл стилей:

```css
.msv-sh { --sh-accent: #FB344A; }
```

## Что модуль умеет

- Прокрутка по месяцам, кнопка «Сегодня», выбор даты.
- Три масштаба; на телефоне мелкий включается сам.
- Поиск по фамилии, комнате или номеру места — ищет по всем броням,
  а не только по видимым на экране.
- Подсказка при наведении: срок проживания, гость, место, начислено,
  оплачено, баланс.
- Карточка проживающего со всеми полями и историей платежей.
- Вертикальная линия текущего дня, подсветка выходных.
- Если на одном месте брони пересекаются (обычно это ошибка в данных),
  они встают в два ряда — конфликт видно, а не спрятан под соседней полосой.
- Работает с клавиатуры: Tab по полосам, Enter открывает карточку,
  Esc закрывает.

## Что модуль намеренно не делает

- Не создаёт и не изменяет брони — только показывает. Для изменений
  предусмотрены `onEdit` и `onOpenProfile`, куда вы подставите свои формы.
- Не ходит на сервер сам. Данные вы передаёте готовым объектом.
- Не переселяет перетаскиванием мышью.
